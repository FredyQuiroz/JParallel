# JParallel

[Español](#español) · [English](#english)

## Español

Ejercicio de Windows para experimentar con un puerto paralelo. Permite ver cómo cambian los valores de entrada y salida que se envían a través de ese conector antiguo.

### Qué puedes hacer

- Consulta valores de entrada y escribe valores de salida en el ejercicio.
- Configura el intervalo con que se actualiza la salida.
- Incluye la vista que presenta el estado de los valores.

### Ejemplo

Explora en la vista cómo cambiarían dos valores ficticios de salida a intervalos regulares. La prueba con hardware requiere un entorno y un controlador compatibles.

### Cómo empezar

El código se creó para Windows y Visual C++. Usa las versiones de MFC o de los SDK que indiquen la solución y sus referencias. Los recursos y componentes externos de la época pueden requerir una copia autorizada. La compilación completa depende de ese entorno original.

Puntos de entrada en el código. [`JParallel.sln`](JParallel.sln), [`JParallel.vcproj`](JParallel.vcproj).

Las fechas del historial se apoyan en Git o en la evidencia disponible de los respaldos. Las fechas reconstruidas a partir de archivos sin zona horaria usan las 12:00 UTC como referencia.

## English

A Windows exercise for experimenting with a parallel port. It shows how input and output values change on that older connector.

### What you can do

- Read input values and write output values in the exercise.
- Configure the interval at which output is updated.
- Includes the view that displays the current values.

### Example

Trace how two fictional output values would change at regular intervals. Hardware testing requires a compatible environment and driver.

### Getting started

The code was written for Windows and Visual C++. Use the MFC and SDK versions indicated by the solution and its references. Historical resources and external components may require an authorized copy. A full build depends on that original environment.

Entry points in the source. [`JParallel.sln`](JParallel.sln), [`JParallel.vcproj`](JParallel.vcproj).

History dates come from Git or available backup evidence. Reconstructed dates from files with no time zone use 12:00 UTC as a reference.
